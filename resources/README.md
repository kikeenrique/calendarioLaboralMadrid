# Source snapshots

This directory keeps source-page snapshots used to understand and maintain the
calendar parsers. The 2026-27 school-calendar snapshot was downloaded from:

https://www.educa2.madrid.org/web/calendario-escolar-de-la-comunidad-de-madrid/calendario-escolar-26-27

The Swift generator continues to fetch the live page. This archived HTML is a
reference for the page structure and labels when EducaMadrid publishes the next
school year or changes the current page.
